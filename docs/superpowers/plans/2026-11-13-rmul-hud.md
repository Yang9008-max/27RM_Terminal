# RMUL 2027 公共作战信息栏 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在复旦 Qt 主窗口中交付由真实 GameData 驱动的 RMUL 3V3 顶部信息栏。

**Architecture:** 保持 `TopInfoBar.qml` 的主窗口入口，替换其 RMUC 基地/前哨站布局，拆出 `RmulTeamPanel.qml` 与 `RmulRobotCard.qml`。控制度直接绑定现有 presence 属性；血量只展示当前会话收到的 GlobalUnitStatus 快照。比赛时钟增加接收有效性，显示服务端时间，不自行倒计时或截断为 300 秒。

**Tech Stack:** Qt 6 Quick/QML、C++ GameData、QtTest、现有 Python/MQTT 验收器。

## Global Constraints

- 赛项为 2027 RMUL 3V3；每方显示重装 1、步兵 3、哨兵 7，4 号仍在协议层解析。
- 规则依据为已归档 RMUL V1.0.0（20261015）PDF17 阵容与五分钟、PDF38 控制度；本阶段不宣称在线规则已更新。
- 控制度首次缺失显示“—”，合法 0 显示“0”，后续缺失保持，换身份/断线清除。
- GlobalUnitStatus 的血量可独立于客户端连接态显示，0 不标为“离线”或自动推断判负。
- 标明“5 分钟制”；无比赛状态时钟为“--:--”，收到 300/0 分别显示“05:00”/“00:00”，暂停与阶段来自服务端。
- 不修改底层 420 秒默认值或旧规则引擎；本阶段不交付地图、TAB 统计、登录角色、旧兑换菜单、重装侧栏迁移。
- 不展示默认队名、经济、最大血量或胜负推演；界面暂用“红方”“蓝方”。
- 改动前标签 `rmul2027-pre-02-rmul-hud`，分支 `rmul2027/02-rmul-hud`；用户已授权在本会话直接执行，不另行请求交接或委派。
