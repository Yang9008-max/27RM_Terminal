# P 面板本地设置修复与验收（2026-11-14）

基线：`rmul2027-pre-05-local-settings-20261114`（`866fc0a`）。
分支：`rmul2027/05-local-settings`；完成标签：`rmul2027-step-05-done`。

## 查明的问题

1. 上轮桌面验收启动脚本在被忽略的 `tmp/desktop-acceptance-20261113/launch-client.ps1`
   中设置了 `RM_DISABLE_AUDIO=1`。旧窗口没有创建音频播放器，面板却仍显示可调音量。
2. 源码按可选资源包策略不包含 `min3bgm.mp3`、`gameBg.mp3` 等历史音乐和部分比赛语音。
   没有音源时调音量不会产生声音，不能用其他比赛效果音假装恢复背景音乐。
3. 提示音量只连接击杀/结算组件，遗漏实际播放短语音的 `m_secondaryOutput`。
   音乐默认实际音量是 80%，界面却显示 50%；跨平台执行的预热还会把短语音静音后恢复成 80%。
4. `setTargetFps()` 只写成员变量，呈现调度完全未读该值，所谓刷新上限并未生效。
5. 鼠标灵敏度原本有接线，但只在已登录重装/步兵的操作页影响机器人鼠标输入。
   P 面板和战术页保留普通指针行为，不能通过设置面板内的指针速度判断其效果。

## 当前行为

| 控件 | 实际作用 | 验收方式 |
|---|---|---|
| 鼠标灵敏度 | 原有机器人输入增益 0.10–3.00 倍；50 对应 1 倍 | 面板显示倍数；实际控制需登录重装/步兵，关闭 P 并进入操作页 |
| 提示音量 | 同时控制短语音、击杀、结算和提示音试听；0 静音 | 调低后点击“试听提示音”；测试也检查全部实际输出对象 |
| 背景音乐音量 | 控制比赛 BGM 和音乐试听，独立于提示音 | 缺源时禁用滑条并提示；“选择音乐”后可调节和试听 |
| 视频刷新上限 | 60/120/144 FPS 视频新帧呈现上限；保留最新帧 | 高频送帧测试检查实际 `frameUpdated` 数量；不改变网络或解码源帧率 |

“选择音乐”使用本地音频文件，仅在本次运行有效。选择不会立即播放，点击“试听 8 秒”最多播放
8 秒；比赛 BGM 继续服从阶段、暂停和结算状态，准备/自检及战斗时使用选择的音源。
试听使用独立播放器，不占用裁判语音队列，也不替换比赛播放器的当前源。

音频禁用或未检测到输出设备时，音量和试听控件禁用并明确给出原因。
正常启动入口为 `tools/windows/start-client.ps1`，不要再复用上述静音验收脚本。
如当前 PowerShell 已设置 `RM_DISABLE_AUDIO`，正常试听前清除该环境变量并重新启动客户端。
这些设置均为本地运行时设置，未新增裁判端消息，也未修改 Windows 总音量或系统鼠标设置。

“试听提示音”使用仓库自行合成的 0.8 秒中性音，不代表倒计时、击杀或结算语音已经安装。
历史音源缺口和安装方法仍见 [可选音效包](../getting-started/optional-audio-pack.md)。

## 自动验证

修复前先运行新增回归测试，确认失败：

- 提示音量设为 23，实际短语音输出仍为 0（预热静音），并未跟随滑条。
- 背景默认实际为 0.8，预期与 UI 一致为 0.5。
- 10 FPS 上限、420 毫秒持续送帧并强制重绘，实际呈现 28 帧，超过最多 5 帧。

修复后 Windows UCRT64 Release 构建和 **33/33 项 CTest** 通过，包含：

- 所有提示输出统一、零音量、越界钳制、背景输出独立。
- 无障碍滑条赋值同样改变实际输出，模型同步不回发；禁用音频同时将独立音效组件静音。
- 禁用音频的 UI 状态，缺失音乐文件拒绝且保留此前音源。
- 音乐和提示音预览使用独立源与音量，互不串线。
- 实际解码资源中的 WAV，播放位置推进、时长约 800 ms 且没有解码错误。
- 10 FPS 限流在 `repaint()` 干扰下仍成立；停止送帧后尾帧最终呈现。
- 提高刷新上限时重排等待中的帧；停止视频后不再呈现残留帧。

## 真实 Windows 窗口

使用 agent-desktop / agent-desktop-windows，启动时清除 `RM_DISABLE_AUDIO`：

- 打开 P，缺少默认背景音乐时明确提示，背景音量和音乐试听禁用。
- 实际鼠标拖动提示音量至 17%；点击提示音试听，窗口显示“正在试听”。
- 打开 Windows 本地文件选择框，选用仓库的 `preview.wav` 作为临时测试源；音乐滑条和试听随即启用。
- 点击音乐试听进入播放状态；该短提示音仅用于选择流程验收，没有作为默认音乐提交。
- 切换刷新上限至 144 FPS；面板布局无溢出，说明文字及控件可见。

截图保存在被忽略的 `tmp/settings-*.png`；不将桌面中的其他应用画面纳入仓库。
完成后重启客户端，清除临时选择并恢复 50% 默认值、默认缺源提示。
本轮验证了音频解码、播放状态和音量路由；没有通过录音核验扬声器实际听感，也未接真实机器人或图传硬件。

## 实现注意

视频用单调时间判断呈现间隔，并在 paintEvent 内再次检查；非视频动画触发的重绘不会绕过上限。
等待期间只保留最新帧，下一次呈现无需等新网络包，不积累队列；正常限帧丢帧不记为渲染停顿。
帧率选项是上限而非保证值，实际值还受源帧率、定时精度和设备性能影响。

此次修复不代表旧 TAB、战术阵容、兑换页面或整个音效事件表已完成 RMUL 迁移。
